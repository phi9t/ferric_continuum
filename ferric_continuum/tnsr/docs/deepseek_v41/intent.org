* Outcome

Implement a text-only DeepSeek V4.1 Flash causal-LM path in =tnsr= with enough
verifiers to establish compatibility with the upstream local inference code and
HuggingFace checkpoint metadata.

* Initial acceptance criteria

- Parse the upstream =deepseek_v41= HuggingFace =config.json= into a typed Rust
  config without losing architecture-specific fields.
- Implement the text causal-LM executable derivation needed for forward logits:
  embedding, hyper-connection residual stream, MLA-style attention with sparse
  window/compressed KV semantics, routed MoE plus shared expert, final norm, and
  LM head.
- Load local safetensors checkpoints through explicit layout, transpose,
  sharding, and quantization adapters.
- Provide deterministic tiny-model tests for every new mathematical primitive.
- Provide upstream parity verifiers that compare selected intermediate tensors
  and final logits against the DeepSeek reference inference code.
- Keep vision encoding, distributed serving, GPU kernels, and production-speed
  speculative decoding outside the first compatibility slice unless explicitly
  approved.
