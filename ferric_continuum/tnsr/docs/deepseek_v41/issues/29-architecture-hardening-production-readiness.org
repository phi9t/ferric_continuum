* Requirements (implemented)

** C1 — extract =checkpoint_io= module, own shard buffers (kills =Box::leak=)

- New =src/deepseek_v41/checkpoint_io.rs=: a deep seam under the loader that
  owns =Vec<u8>= shard buffers and builds an owned name -> entry index from the
  safetensors header (=SafeTensors::read_metadata= + =data_offsets=). No
  =Box::leak=; a =Checkpoint= frees all shard memory on drop. This matters for
  the real 510GB release and any long-lived server that opens more than one
  checkpoint.
- Total interface: =Checkpoint::{open_single,open,has,float,float_exact,
  linear_weight}=; decodes bf16/f16/f32 + block-scaled FP8-E4M3 / FP4-E2M1.
- =load.rs= now imports from =checkpoint_io=; all dtype-decode / dequant / index
  logic moved out of the loader.

** P4 — input validation (NaN reject + config ranges)

- =checkpoint_io= rejects non-finite values after FP8/FP4 dequant with a named
  error (=reject_nonfinite=) rather than silently poisoning downstream matmuls.
- =DeepSeekV41TextConfig::validate= runs after both parse paths
  (=from_hf_json= / =from_inference_json=): positive-geometry fields, rope-dim
  <= head-dim, top-k <= expert count, heads divisible by =o_groups=, positive
  finite =rms_norm_eps= / =rope_theta=. Test:
  =semantically_invalid_config_is_rejected_by_validate=.

** P3 — NaN-safe CLI top_k

- =src/bin/deepseek_v41_infer.rs= =top_k= uses =f32::total_cmp= instead of
  =partial_cmp().unwrap()=, so a NaN logit sorts deterministically instead of
  panicking.

** P2 — panicking public API on the DSpark / multimodal path -> =Result= seams

- =DeepSeekV41DsparkHead::try_forward_spec= is the new fallible entry
  (empty ids, missing stage tensors, shape mismatch all return named errors);
  =forward_spec= is a thin panicking wrapper for tests.
- =forward_embed= / =forward_head= / =first_stage= / =last_stage= now return
  =Result= instead of =expect=.
- =merge_image_embeddings= returns =Result= (span overflow / unknown token type
  are named errors) instead of =assert!/panic!=; the multimodal forward
  propagates it with =?=.
