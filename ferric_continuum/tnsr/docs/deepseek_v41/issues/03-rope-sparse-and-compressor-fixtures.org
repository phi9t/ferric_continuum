Required Rust APIs:

- =YarnRopeConfig { rope_head_dim, max_seq_len, original_seq_len, rope_theta, rope_factor, beta_fast, beta_slow }=
- =precompute_freqs(config: &YarnRopeConfig, seqlen: usize) -> Vec<[f32; 2]>= or an equivalent typed representation that preserves cos/sin pairs per position and pair index.
- =apply_rotary_adjacent_pairs(data: &mut [f32], shape: RopeShape, freqs: &[...], inverse: bool)= where =RopeShape= supports both =[B,S,D]= and =[B,S,H,D]=.
- =window_topk_indices(window_size: usize, batch: usize, seqlen: usize, start_pos: usize) -> Vec<i32>= matching upstream =-1= sentinel behavior.
- =select_candidate_blocks(logits: &[f32], shape: CandidateShape, compress_lens: CandidateLens, topk_blocks: usize, block_size: usize) -> Vec<bool>=.
- =compress_ratio_one(kv: &[f32], norm_weight: &[f32], eps: f32) -> Vec<f32>= for the ratio-1 compressor path.
- =compress_ratio_n(kv: &[f32], score: &[f32], ratio: usize, norm_weight: &[f32], eps: f32) -> Vec<f32>= for prefill groups with ratio > 1.

Fixture generator requirements:

- Import the mirrored upstream Python files by path from =ferric_continuum/tnsr/third_party/deepseek_v41/upstream/inference=.
- Generate deterministic tensors with fixed small shapes and integer-ish values
  so fixture diffs remain reviewable.
- For each fixture, include:
  - upstream function name
  - input values
  - expected output values
  - absolute tolerance
  - source file path and line-hint string
- Do not require released model weights.

Unit verifier requirements:

- Op verifier for YaRN frequencies checks selected cos/sin values at positions
  0, 1, 7, and a position greater than =original_seq_len= in a small config.
- Op verifier for adjacent-pair RoPE checks forward and inverse rotation.
- Op verifier for window top-k checks prefill and decode cases, including
  =-1= padding.
- Op verifier for candidate block selection checks forced inclusion of the
  newest block and exclusion of unreachable =-inf= blocks.
- Op verifier for compressor checks:
  - ratio 1 path applies =wkv= output normalization with no softmax pooling.
  - ratio > 1 prefill path pools complete groups and carries no trailing group
    in the fixture case.
