Block/unit verifier requirements:

- Layer verifier for =DeepSeekV41Attention= checks q path, KV path, sparse index
  consumption, grouped =wo_a= projection, and output shape against fixture data.
- Layer verifier for =DeepSeekV41MoE= checks selected expert indices, routed
  weighted sum, shared expert addition, and output dtype/shape.
- Layer verifier for =DeepSeekV41Engram= checks text-token update and masked
  token no-op behavior.
- Block verifier checks one complete block for each representative mode:
  - =compress_ratio= 0 sliding-window only
  - KV source layer
  - index source layer
  - reuse layer
  - Engram layer
- Model verifier checks a tiny multi-block text model emits logits shaped
  =[B,S,V]= and rejects unsupported image-token inputs with a clear error.

- No tokenizer or prompt rendering.
- No vision/image execution.
- No DSpark speculative decoding.
- No production optimized sparse attention kernel.
