  - =--image-patches <path>= to a JSON file carrying =[{n_vit_h, n_vit_w,

* Resolution

Landed the multimodal CLI path and prompt-encoding parity fixture.

- =deepseek_v41_fixture_gen.py=: added =generate_vl_prompt= + a =vl-prompt=
  family. It path-imports upstream =image_processor.py=, stubs the tokenizer
  (=<image>= -> id 4, other words -> deterministic byte-sum ids in {1,2,3}),
  provides an =encoding= module shim carrying the real =IMAGE_PLACEHOLDER=, binds
  real =torch= onto the module so =image_token_types= builds a real Tensor, and
  monkeypatches =load_image= to return tiny deterministic patches. It calls the
  real =prepare_vl_inputs= and writes =prompt_vl_fixture.json= with the expanded
  =tokens=/=token_types= and per-image =(start, n_vit_h, n_vit_w, n_llm_h,
  n_llm_w, token_types)=.
- =deepseek_v41_infer.rs=: added =--multimodal= (default stays text-only),
  =--token-types=, and =--image-patches <json>=. The CLI runs each image's
  patches through the loaded vision tower (=encode_image=), rebuilds the span
  =image_token_types=, and calls the new =forward_multimodal_with_seed=. Image
  token id is rejected only in text-only mode. DSpark/speculative flags still
  rejected; multimodal decode past prefill is refused. =--dump-logits= writes
  =model_type: "deepseek_v41_multimodal"= plus a =token_types= echo.
- =load.rs=: added =forward_multimodal_with_seed= (seeds gate token counts, then
  =try_forward_multimodal=).
- =deepseek_v41_model_test.rs=: added =vl_prompt_fixture_expands_image_span=,
  reconstructing the =[START, (IMAGE*w, NL)*h, END]= layout and checking the
  fixture's tokens/token_types and =num_image_tokens = n_llm_h*(n_llm_w+1)+2=.
- =BUILD.bazel=: wired =prompt_vl_fixture.json= into =deepseek_v41_model_tests=
  data and added =serde=/=serde_json= deps to =deepseek_v41_infer=.
