* Context

The vision tower is a full-bidirectional-attention ViT over one image with 2D
RoPE. This ticket implements the ViT math and pins op/layer/block fixtures
against upstream =vision.py=. The 2D RoPE is half-split and MUST NOT reuse the
text adjacent-pair RoPE.

Read first:

- =../spec.org= (ViT)
- =../upstream/inference/vision.py= (=get_vision_cos_sin=, =apply_rotary=,
  =PatchEmbed=, =Attention=, =MLP=, =Block=, =ViT=, =RMSNorm=)

* Requirements

- Create =ferric_continuum/tnsr/src/deepseek_v41/vision.rs= (ViT pieces) holding:
  - =vision_cos_sin(n_h, n_w, rope_dim, theta) -> (Vec<f32>, Vec<f32>)= matching
    =get_vision_cos_sin= (inv_freq over =arange(0,dim,2)/dim=, freqs stacked from
    (hpos,wpos), flattened; cos/sin per patch).
  - =apply_rotary_half_split(x, cos, sin, n, n_heads, head_dim)= implementing the
    =chunk(2)= half-split rotation.
  - =VisionPatchEmbed { proj_w, proj_b }= = Linear over flattened =3*patch^2=.
  - =VisionAttention { wqkv, wqkv_b, wo, wo_b, n_heads, head_dim }= = full
    bidirectional SDPA (softmax over all patches, no causal mask), RoPE on q,k.
  - =VisionMlp { w1, w2 }= = chunked SwiGLU (=silu(gate)*up=), no bias.
  - =VisionBlock { norm1, attn, norm2, mlp }= = pre-norm residual pair with
    vision RMSNorm.
  - =VisionTower { patch_embed, blocks, norm, rope_dim, rope_theta }= with a
    =forward(patches, n_h, n_w) -> [n_patch, dim]=.
- Vision RMSNorm eps is =1e-6= (upstream default), distinct from the text
  =1e-20=. Reuse =crate::ops= where the math is genuinely identical
  (=linear=, =silu=); implement the half-split RoPE and full SDPA locally.
- Add fixture families =vision-rope=, =vision-attn=, =vision-block= to
  =deepseek_v41_fixture_gen.py=, instantiating the upstream =vision.py= classes
  with tiny deterministic weights (monkeypatched kernels not needed — vision.py
  is pure torch). Emit =vision_rope_fixture.json=, =vision_attn_fixture.json=,
  =vision_block_fixture.json= with inputs, weights, expected outputs, tolerance,
  and source hints.
- Add op/layer/block tests to the vision test target, wired into BUILD data.
