should teach the tensor contracts it implements. Several core paths already do
this well, especially the hyper-connection tensor conversion seam, but the

flattened offset formulas.

- Preserve behavior and existing public interfaces.
- Improve educational readability in high-traffic DeepSeek paths by naming
  semantic dimensions and flattened layouts at the point of use.
- Prefer small private helpers, comments, and local variable names over broad
  architectural changes.
- Add or update focused tests before production edits when a helper captures a
  shape contract.

* Out of scope

- Real checkpoint admission or download.
- Native FP8/FP4 execution.
- Tensor-parallel serving.
- New DeepSeek model behavior.
- Publication, branch landing, or merge.
