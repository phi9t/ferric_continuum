# Teaching Notes

- Prefer repository-grounded lessons that end in a trace, prediction, measurement, or small implementation.
- Keep training and inference in view, but establish the actual execution boundary before introducing parallelism strategies.
- Do not assume proficiency in CUDA, Rust, C++, Bazel, or distributed systems until the learner demonstrates it.
- Use Markdown for all lesson and reference material. The workspace is remote and the learner does not have browser access.
