=Tensor= handle. Typed operation wrappers and separate ordinary/context-
parallel Qwen3 attention derivations preserve tensor identity, autograd
topology, and the legacy APIs. Wave B static extents and Wave C named runtime
boundaries are specified in the Markdown lesson but remain unimplemented.

work because it would change valid-input numerics.
