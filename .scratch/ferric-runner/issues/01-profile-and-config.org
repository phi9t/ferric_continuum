* Context

The Ferric runner needs a checked-in profile and a small config module before it
can build bwrap plans or run commands. The profile makes peer-repo mounts
explicit so Ferric can study GPU-kernel code across repositories without
hardcoding each repo in the CLI.

* Requirements

- Add ~tools/ferric_run/profiles/gpu-kernel-study.json~.
- Add config loading and validation for:
  - primary repo name
  - repo map
  - host path
  - sandbox path
  - mode: ~ro~ or ~rw~
  - required flag
- Resolve ~repo://self~ to the Ferric git/worktree root.
- Default peer repositories to read-only when mode is omitted.
- Treat missing required repos as errors and missing optional repos as warnings.
- Preserve CLI/env/profile precedence for rootfs and bwrap values.

* Out of scope

- Building bwrap argv.
- Writing run records.
- Executing commands.
- CUDA checks.

* Verification

- Unit tests for profile loading and validation.
- Unit tests for ~repo://self~ resolution.
- Unit tests proving peer repos default to ~ro~.
- Unit tests proving optional missing peers warn while missing required repos
  fail.
