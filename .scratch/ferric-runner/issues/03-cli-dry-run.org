* Context

Dry-run is the first user-visible command surface. It proves the profile,
preflight, plan, and run-record contract without requiring a working rootfs or
launching bwrap.

* Requirements

- Add ~tools/ferric_run.py~ CLI entrypoint.
- Support:
  - ~--profile~
  - ~--rootfs~
  - ~--bwrap~
  - ~--cuda~
  - ~--dry-run~
  - generic command argv after ~--~
- Implement bwrap resolution order:
  1. ~--bwrap~
  2. ~FERRIC_BWRAP~
  3. ~PATH~
- Implement rootfs resolution through CLI/env/profile defaults.
- Create a run directory and write command, preflight, plan, and result
  artifacts for dry runs.
- Do not launch bwrap in dry-run mode.

* Out of scope

- Real execution.
- CUDA mount projection.
- Named workflow shortcuts.

* Verification

- Unit tests for CLI parsing and precedence.
- Dry-run integration test with a temporary rootfs path and harmless command.
- Assert expected artifacts exist and result marks the command as not executed.
