* Context

The local text model currently behaves like a flat layer loop. DeepSeek V4.1
Flash uses a causal encoder-decoder organization: 20 encoder layers, then 20
decoder layers whose global KV is projected from final encoder hidden states.

* Requirements

- Represent encoder and decoder layers explicitly in the Rust model structure.
- Add config validation for the 20+20 release split while preserving tiny-fixture
  configurability.
- Carry final encoder hidden states into decoder global-KV construction.
- Preserve existing Hyper-Connection and MoE behavior across the boundary.
- Add a fixture-level test that fails if decoder layers source global KV from the
  decoder residual stream instead of final encoder hidden states.

* Out of scope

- Optimized serving cache migration.
- Distributed tensor parallel placement.
