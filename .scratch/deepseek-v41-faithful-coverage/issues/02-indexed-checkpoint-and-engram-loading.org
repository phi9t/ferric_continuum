* Context

The release checkpoint is indexed by =model.safetensors.index.json= and shard
files named =model-000xx-of-00048.safetensors=. The local loader currently works
best for single-file or converted =-mp= layouts, and Engram tables are checked
but not loaded into the runtime.

* Requirements

- Load tensors through the HF index JSON and public shard names.
- Preserve support for existing converted/local fixture layouts.
- Load Engram tensors needed by the runtime path:
  - =engram.*.embed.weight= or the release-equivalent table names.
  - =engram.*.wkv.weight= and related q/k weights.
- Add negative tests for missing required Engram tensors when Engram is enabled.
- Add tiny indexed-shard fixture coverage that proves the loader resolves a
  tensor from the JSON index rather than guessing shard names.

* Out of scope

- Full 48-shard release model validation.
- GPU loading or quantized-kernel execution.
