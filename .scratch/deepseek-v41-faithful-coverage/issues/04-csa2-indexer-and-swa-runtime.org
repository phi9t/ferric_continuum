* Context

The local attention path has helper functions for windows and candidates, but
the runtime attention still does not faithfully execute upstream CSA2. Faithful
coverage requires the actual model forward path to compose SWA with global
compressed sparse attention.

* Requirements

- Implement SWA ring-cache behavior in actual attention for both prefill and
  decode, using the same window-index semantics as upstream =get_window_topk_idxs=.
- Implement CSA2 mode behavior:
  - Full: produce global KV, indexer K, and Top-K indices.
  - Reindex: reuse global KV and indexer K, compute fresh Top-K from this layer's
    own query and =weights_proj=.
  - Reuse: reuse global KV and Top-K indices from the configured source layer.
- Implement the V4.1 indexer path with =weights_proj=, =wk=, =k_norm=, index K
  cache, candidate blocks, and candidate masks.
- Add runtime tests that fail if =window_size= is ignored or if Reindex/Reuse
  collapse to Full behavior.

* Out of scope

- Native FP4 cache kernels.
- Performance parity for million-token serving.
