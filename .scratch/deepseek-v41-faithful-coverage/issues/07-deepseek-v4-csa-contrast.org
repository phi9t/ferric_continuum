* Context

The user explicitly asked to cover CSA from DeepSeek V4 as well as CSA2. This is
not a request to implement a V4 model; it is a request to faithfully preserve the
contrast so V4.1 tests do not accidentally encode older CSA/HCA assumptions.

* Requirements

- Add a short source-grounded note, either in the DeepSeek V4.1 docs or test
  comments, naming the V4-to-V4.1 attention changes:
  - V4 used a CSA/HCA hybrid framing.
  - V4.1 Flash uses pure CSA2.
  - V4.1 shares global KV, indexer K, and Top-K indices according to
    Full/Reindex/Reuse modes.
  - V4.1 removes or avoids older CSA assumptions such as overlapping source
    entries and absolute-position compressor behavior unless primary-source
    evidence requires retaining them.
- Add regression names/assertions that make the CSA2 invariants visible when
  reading test output.
- Do not add a second V4 runtime or pretend the local mirror is a V4 source.

* Out of scope

- DeepSeek V4 checkpoint loading.
- Numeric parity against a V4 model.
