#+TITLE: Deepen causal GQA semantics
#+TYPE: grilling
#+STATUS: resolved

* Outcome

Make ordinary and context-parallel grouped-query attention easier to read and
reason about as executable derivations, while sharing only incidental mechanics
that do not hide transformer mathematics.

The design may deepen beyond GQA into typed transformer tensors when necessary:
named dimensions should expose mathematical roles, and distinct operation
variants should retain pristine implementations without runtime strategy
branches.

* Route

Gated architectural path. The change moves an internal semantic seam and must
preserve forward/backward and multi-output autograd invariants.

* Accepted scope

- Preserve the existing public ordinary GQA, raw context-parallel GQA, autograd,
  and =Qwen3Attention= interfaces.
- Preserve public =GqaShape= and =GqaShape::group_size=, public
  =ContextParallelGqaShape=, raw context-parallel forward/backward functions,
  saved-state shape, and named gradient result vectors.
- Treat explicit mathematical structure as a first-order requirement. Some
  duplication is acceptable when it keeps forward/backward equations, shapes,
  causal visibility, or gradient ownership local and readable.
- Preserve equal contiguous context shards, materialized batch-major global
  K/V, saved probability blocks, f32 CPU execution, and current debug identity.
- Keep ordinary and context-parallel numerical behavior and gradients equivalent
  to the current implementation.

* Out of scope

- Ring or online-softmax execution.
- CUDA or NCCL execution.
- Ragged shards, explicit position IDs, KV cache, or full-model sharding.
- Public interface or stable trace-schema changes.

* Acceptance evidence

- Visible red-green behavior slices at the approved public test seam.
- Existing ordinary and context-parallel GQA parity and gradient tests pass.
- Existing Qwen3, autograd, debug, distributed, scaling, and library tests pass.
- Standards and Spec review have no unresolved blocking findings.
- Independent branch defect review passes before human handoff.

* Authority boundary

The agent may design, create isolated implementation worktrees, edit code/tests
and tracker artifacts, and run verification. Commit, push, pull-request creation,
and merge require separate explicit human authorization; merge is always human.

* Answer

The completed implementation keeps ordinary and context-parallel GQA as
separate explicit forward/backward derivations, adds named semantic axes and
extent evidence over the existing tensor handle, and isolates only equal-
contiguous ownership mechanics in a private layout module. Independent scalar,
finite-difference, metamorphic, cross-degree, autograd, and Qwen3 verifiers all
pass. Wave B/C static and interchange refinements and ring/CUDA/NCCL execution
remain explicitly deferred.
