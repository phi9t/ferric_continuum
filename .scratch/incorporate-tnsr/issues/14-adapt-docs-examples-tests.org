Doc/example decisions:

- Added a module-local `README.md` as the Bazel-first replacement for the
  standalone README. It documents current monorepo APIs: stable
  `tnsr.debug_trace` JSON, CPU inference primitives, scaling memory reports,
  distributed symbolic reports, Qwen3 binaries, and the existing
  `//ferric_continuum/tnsr:tnsr_demo` artifact flags.
- Added `docs/debugging.md` as the Bazel-first debugging guide, with Bazel
  build/test/run commands before supplementary Cargo tooling and LLDB examples
  against `bazel-bin`.
- Kept external `examples/tiny_block.rs` represented by the maintained
  `tnsr_demo --dot ... --trace-json ...` path rather than adding a second demo
  binary.
- Did not import web viewer docs, generated DOT/JSON artifacts, frontend
  tooling, or stale Cargo subcommands.
- Corrected local docs/rustdoc comments that described `tnsr` as globally
  CPU-only. The docs now distinguish the default CPU build, symbolic
  distributed reports, and the opt-in Bazel CUDA forward path.

Behavior test adaptation:

- Extended `//ferric_continuum/tnsr:playground_cli_tests` to run the Bazel
  runfiles copy of `tnsr_demo`, write caller-selected DOT and JSON artifacts,
  parse the JSON, and assert the stable `tnsr.debug_trace` schema.
- Added `@crates//:serde_json` only to that test target because the new behavior
  assertion parses the generated JSON artifact.
