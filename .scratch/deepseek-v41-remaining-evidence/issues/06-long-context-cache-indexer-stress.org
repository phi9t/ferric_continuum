The current tests cover tiny SWA and CSA2 behavior. The release claims depend on
long-context execution: sliding-window cache wraparound, CED decoder use of
encoder-derived global KV, CSA2 Full/Reindex/Reuse shared state, and indexer

* Outcome Packet

Outcome:

- A bounded stress suite proves cache/indexer invariants across prefill and
  decode positions that cross the SWA window, source-layer, and CED boundaries.

Mode:

- delivery

Non-goals:

- No million-token full model run.
- No performance benchmark.
- No native quantized kernels.

Allowed change surfaces:

- DeepSeek V4.1 model/attention/sparse tests and the smallest runtime changes
  needed to expose verifiable state safely.

* Requirements

- Add reduced-geometry tests that run enough decode steps to wrap
  =window_size= at least twice.
- Assert that local SWA reads only the expected causal window after wraparound.
- Assert CED decoder global KV remains sourced from final encoder hidden state
  while decoder-local SWA continues to update independently.
- Assert CSA2 =Full= publishes compressed KV, index K, Top-K, and candidate
  mask state under the correct source layer.
- Assert CSA2 =Reindex= recomputes Top-K from cached index K without replacing
  compressed KV from the KV-source layer.
- Assert CSA2 =Reuse= reads cached Top-K from the configured index source.
- Add a receipt describing the reduced geometry, sequence positions, and why it
  discriminates cache/indexer regressions.

Evidence:

Candidate:

Reuse rule:

Invalidation rule:
