* Post-Review Execution

This pass addressed the final local conformance gap found during review:
CSA2 release source layers with =compress_ratio > 1= now construct a
=wkv= + =wgate= compressor and execute the upstream-style prefill path:

- ratio 1 remains =wkv -> RMSNorm= with no gate;
- ratio N prefill projects =wkv= and =wgate= to =head_dim=, drops incomplete
  trailing groups per batch, softmax-pools over the ratio dimension, then
  applies RMSNorm;
- ratio N decode state remains an explicit unsupported boundary rather than a
  silent approximation.

The post-review pass also corrected stale educational module headers and the
private rustdoc link that was warning in =typed_tensor_compile_tests=.

* Human Promotion Boundary

This packet supports local review of the current DeepSeek V4.1 candidate. It
does not authorize merge, push, publication, checkpoint download, high-cost
long-context execution, native quantized kernel work, or TP serving work.

Promotion to a stronger release claim requires, at minimum:

- a real-checkpoint asset admission receipt;
- numeric real text and multimodal parity;
- numeric real DSpark =forward_spec= parity or an explicit accepted limitation;
- a native FP8/FP4 execution ticket if performance or memory-footprint claims
  are made;
- a TP serving parity ticket if multi-rank serving claims are made.
