* Context

Ticket 08 selects the durable architecture direction for DTensor-style mesh
simulation. This ticket turns that recommendation into the canonical simulator
path that later TLA+ work can depend on.

The graduated path must be executable, deterministic, and explicit about the
schedule vocabulary. The distributed-training TLA+ track is blocked until this
ticket and the handoff ticket both resolve.

Implemented ticket 09 as the graduation of the selected plan-first simulator
path.

- Report: [[file:../reports/09-graduation.org][09 graduation report]]
- Stable public entrypoint:

#+begin_src rust
run_tiny_dense_mesh_simulation(dims, injection_plan)
#+end_src

This entrypoint is a thin wrapper over the ticket 08 candidate:

#+begin_src rust
MeshSimPlan::tiny_dense_training(dims)?.execute(injection_plan)
#+end_src

Added a deterministic report surface on ~MeshSimPlanReport~:

#+begin_src rust
report.deterministic_run_report()
#+end_src

Added the TLA+ handoff vocabulary as ~MeshSimStableVocabulary~:

- mesh axes and rank-coordinate ordering
- process group construction and ordered membership
- placement names
- layout transition names
- collective kinds and signatures
- trace event names and fields
- failure record fields

Added the DualPipe-level schedule vocabulary:

- ~DualPipeSchedule~
- ~DualPipeChunk~
- ~DualPipeComponent~
- ~DualPipeComponentKind~
- ~DualPipeOverlap~

Forward chunk components:

- ~attention~
- ~all_to_all_dispatch~
- ~mlp~
- ~all_to_all_combine~
- ~pp_communication~

Backward chunk components:

- ~attention_input_gradient~
- ~attention_weight_gradient~
- ~all_to_all_dispatch_gradient~
- ~mlp_input_gradient~
- ~mlp_weight_gradient~
- ~all_to_all_combine_gradient~
- ~pp_communication~

The schedule carries explicit dependencies and one legal paired
forward/backward overlap:

#+begin_src text
dualpipe.forward[0].mlp || dualpipe.backward[0].attention_input_gradient
#+end_src

Illegal same-direction overlap is rejected as:

#+begin_src rust
PlanError::Schedule(FailureRecord { ... })
#+end_src

The non-selected wrapper DTensor and tensor-native layout paths remain available
as tracer-bullet evidence and test-support/control paths only. They were not
promoted to the canonical simulator interface.

Unsupported and deferred semantics:

- Ticket 10 still owns the TLA+ handoff implementation.
- MoE/EP execution semantics are still deferred; ticket 09 only adds
  all-to-all component labels at the schedule boundary.
- CUDA/NCCL execution is not implemented.
- Asynchronous collective progress is not implemented.
- Overlap is represented and validated at schedule level, not executed through
  an async runtime.
- Fault recovery, retry, and rescheduling are not implemented.
- Derived mesh views such as ~loss~ and ~fsdp~ remain named vocabulary, not
  first-class simulator axes.
- Multi-axis layout propagation, uneven sharding, sparse meshes, and non-sum
  partial reductions remain unsupported.
- The simulator is not integrated with real ~tnsr~ autograd scheduling.
