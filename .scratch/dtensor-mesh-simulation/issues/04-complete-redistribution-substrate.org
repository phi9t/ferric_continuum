* Context

The common substrate branch added ~reduce_scatter_sum~, ~broadcast~, and
~local_slice~, but final scoped re-review found a real remaining gap:
~reduce_scatter_sum~ does not yet model ~Partial(sum) -> Shard(dim)~ because
it has no tensor-dimension parameter and returns flattened local tensors.

This ticket blocks the three architecture tracer bullets. They need a reliable
redistribution substrate before their ergonomics can be compared fairly.

Implementation plan:

- [[file:../plans/2026-08-18-redistribution-substrate-plan.org][DTensor redistribution substrate implementation plan]]

* Requirements

- Update reduce-scatter semantics so ~Partial(sum) -> Shard(dim)~ preserves the
  original tensor rank and shards the requested tensor dimension.
- Add a dimension-aware API. A concrete acceptable surface is:

#+begin_src rust
pub fn reduce_scatter_sum(
    &mut self,
    axis: MeshAxis,
    shard_dim: usize,
    phase: TrainingPhase,
    shards: &[TensorValue],
) -> Result<Vec<TensorValue>, CollectiveError>;
#+end_src

- Validate that ~shard_dim~ is in range and the dimension is evenly divisible
  by the axis size. Return typed errors instead of panicking.
- Preserve axis-local rank groups. A reduce-scatter along ~dp_shard~ must reduce
  only ranks that differ on ~dp_shard~ while sharing the other 5D coordinates.
- Return local shapes with only ~shard_dim~ reduced by the axis size.
- Record a ~MeshTraceEvent::Collective~ with ~CollectiveKind::ReduceScatter~,
  axis, bytes, and participating ranks.
- Keep ~broadcast~ and ~local_slice~ semantics aligned with the same
  dimension-aware shape model where relevant.
- Update the smoke path or tests only as needed to exercise the fixed
  semantics; do not start any architecture tracer bullet here.

* Out of scope

- Multi-axis shard order.
- Uneven/ragged shards.
- Async collectives.
- Real process/NCCL/CUDA execution.
- MoE/EP.
- Full DTensor wrapper/native/plan tracer bullets.

- API: ~CollectiveSimulator::reduce_scatter_sum(axis, shard_dim, phase, shards)~.
- Semantics: axis-local elementwise sum, then contiguous row-major slicing of
  ~shard_dim~ using each rank's coordinate on the collective axis.
- Validation: typed errors for out-of-range ~shard_dim~ and uneven requested
  tensor dimension.
- Trace: records ~MeshTraceEvent::Collective~ with
  ~CollectiveKind::ReduceScatter~, axis, bytes, and participating ranks.
- Scope: no wrapper/native/plan tracer bullets, CUDA/NCCL, async collectives,
  MoE/EP, or uneven shard support added.
