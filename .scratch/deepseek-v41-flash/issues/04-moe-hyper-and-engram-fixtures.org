* Context

This ticket adds unit verifiers for DeepSeek V4.1's non-attention text
components. It must cover both op-level behavior and layer-level behavior,
because full logits can look plausible while routing, HC mixing, or Engram
updates are wrong.

Unit verifier requirements:

- Op verifier for =sqrtsoftplus= checks exact selected experts differ from raw
  top-k when correction bias changes the order.
- Op verifier for route weights checks normalization uses =+1e-20= and
  =route_scale=.
- Op verifier for SwiGLU checks =up= clamps to both sides and =gate= clamps
  only above before =silu(gate) * up=.
- Op verifier for HC split checks pre/post/comb shapes and row/column sums of
  =comb= after Sinkhorn are within tolerance.
- Layer verifier for HC pre/post checks collapse and expansion on a tiny
  =[B,S,hc_mult,D]= residual.
- Op verifier for Engram layout checks prime bucket assignment and per-layer
  offsets against upstream.
- Op verifier for Engram hash state checks prefill and decode update on text
  tokens.
- Layer verifier for Engram update checks signed-square-root gate and token mask
  behavior.
